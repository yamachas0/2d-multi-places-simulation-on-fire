# 品川駅前 — 教室で渡す事前知識 (Layer 3 のみ)

このドキュメントは座学Phase で参加者に与える「議論の素材としての知識」。
歴史・文化・統計・全体像の概念だけ含み、現場でないと分からない知覚情報 (Layer 1/2) は含まない。
それらは Phase B の現地で各 place を歩いて初めて拾う。

## 全体像 (大局的な性格)

- 品川駅は東(港南口)と西(高輪口)で性格が異なる
  - 港南口=オフィス街・新しい再開発エリア
  - 高輪口=ホテル群・第一京浜・古い街並み・坂
- 駅前エリアの境界は、大きく見れば
  - 北: シーズンテラス〜芝浦中央公園
  - 南: グランドコモンズ・インターシティ南端
  - 東: 港南ペンシルビル街を抜けた運河あたり
  - 西: 二本榎通り (それより西は高輪台駅エリアの閑静な住宅街)

## 歴史的コンテクスト

- 品川は江戸期の **旧東海道** の宿場町、玄関口としての文脈を持つ
- **高輪築堤** など、江戸〜明治期の鉄道インフラ史も品川と結びつく
- 品川は歴史的に **高輪より下に見られてきたエリア** で、駅前に **食肉市場(旧屠殺場)** が今も残るのも、その経緯と無関係ではない
- 港南口エリアの再開発は1990年代以降、グランドコモンズ群の建設で本格化
- 高輪ゲートウェイ駅 (2020年開業) と一体的な大規模再開発が進行中

## 業務・産業の集積

- 港南側のオフィス街:
  - グランドコモンズ群 (NTT・キャノン・マイクロソフト・太陽生命・Vタワー等)
  - インターシティ
  - 品川シーズンテラス
  - ソニー本社、コクヨ
- カンファレンス・イベント機能 (インターシティ・国際会議場 等)
- 新幹線駅前という性格上、出張族の往来が常時厚い

## 再開発の動き

- **品川駅北口広場 / 駅街区** : JR線路上空で工事進行中、大規模交通広場
- **環状2号線** : 線路上空の高架道路、巨大構造物
- **A地区・D地区** 等の駅前再開発計画
- **高輪ゲートウェイ駅** とそこに繋がるデッキで芝浦中央公園と直結予定

## 生活・文化の層

- 旧東海道沿いの商店、寺社
- 高輪台側の閑静な住宅街
- 港南ペンシルビル街 (飲食・スナック・風俗が混在する雑多な飲み屋街)
- 食肉市場 = 市場関係者以外立ち入れない閉鎖エリア、駅前にこの規模が残るのは特異
- 三菱関東閣 (旧岩崎邸、重要文化財) など、緑に包まれた邸宅遺構も残る

## 交通

- JR線 (山手・京浜東北・東海道・横須賀・上野東京ライン)
- 京急本線・空港線 (羽田アクセス)
- 東海道新幹線
- 国道15号 (第一京浜) — 駅西側を南北に貫く幹線
- 都営バス・空港バス・タクシー
- 将来: **リニア中央新幹線** の起点予定地

## 未来的な取り組み (現時点で議論されている方向性、決まっているわけではない)

- 都市OS (まち全体のデータ統合・運用)
- 5G・実証実験
- MaaS (モビリティ統合)
- ロボット・ドローン
- デジタルツイン (まちの3Dコピー)
- サーキュラーエコノミー

これらはあくまで構想段階。現地で実際に何が動いているかは別問題で、Phase B で歩いて確かめる対象。
